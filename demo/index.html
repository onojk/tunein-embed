tunein-embed

A drop-in web player for live Icecast & SHOUTcast radio. Paste your stream URL to test it, then copy the snippet. Docs & source on GitHub.

Try:

Embed it

1. Script tag (any site that allows <script>)
2. iframe (WordPress.com, Squarespace, Wix…)
3. WordPress shortcode (with the plugin installed)

No now-playing info or a flat visualizer? Your stream server isn't sending CORS headers — playback still works. See CORS & HTTPS for one-line fixes.
